## 同步方式

本机 SSH 推送未通过认证，HTTPS Git 推送也缺少登录凭据；首次同步使用已连接、具备写权限的 GitHub 工具完成。无须在聊天中提供密码或令牌。

工作区已初始化 Git，`origin` 指向上述仓库，用于跟踪差异。后台同步使用当前任务的 GitHub 连接；普通 `git push` 仍需另行配置本机 Git 登录。

每次先读取远端分支、比较上次同步基线。没有变更不提交；同一路径的本地与远端均修改、出现删除、大文件或敏感内容时停止自动发布并请求处理。保留远端新增文件，不强推、不自动覆盖冲突。

已在当前任务创建每小时检查一次的后台同步。专用基线为 `refs/refsync/last-synced`；后台只更新此引用，不擅自移动用户分支或改变暂存区。本地运行要求电脑和应用保持运行，无法保证关机期间实时同步。

`GitHub同步/repo.bundle` 是另一个工作环境生成的历史快照，不自动视为最新事实；更新时须与当前工作区和远端分别比较，不能直接覆盖新提交。

同步成功只表示代码和文档已上传，不代表检测效果已通过独立验证。当前核查结果以有明确日期、输入、版本和实测记录的文档为准。
