# 04_决赛演示 · RefSync-QA 算法实时演示

演示只做三件事：**检测 → 修复 → 对比**。现场真跑 v3.2 算子，所有数字来自这次运行写出的文件；
不联网、不依赖外部 CDN，页面与算法都在本地。

## 依赖

- Python 3.9+，`numpy` / `pyarrow` / `pillow`（算子自身依赖，见 `03_复赛算子/Raw_data/requirements.txt`）
- 仅用标准库起 HTTP 服务，无需 Flask/Django

```bash
cd <仓库根目录>
python3 -m venv .venv
.venv/bin/pip install -r 03_复赛算子/Raw_data/requirements.txt
```

## 启动

```bash
cd 04_决赛演示 && ../.venv/bin/python server.py --port 8765
# 浏览器打开 http://127.0.0.1:8765/
```

macOS 也可双击 `start_demo.command`（会自动选可用 Python、清理端口）。

## 三步

| 步骤 | 做什么 | 操作 |
|---|---|---|
| **1 检测** | 调用算子 `--no-repair`：计时、89 条轨迹逐条点亮、四类问题实时累计；跑完显示需复核数、帧级定位行数、问题区间、帧级全景图、五维评分与报告文件 | 按空格或点「开始检测」 |
| **2 修复** | 调用完整算子（检测 → 修复 → 回读核验 → 复检 → 切段）：修复副本逐个出现；跑完显示三种处理方式的可训练帧对比、决策流向、拒修原因、治理叠加层文件 | 按空格或点「开始修复」 |
| **3 对比** | 默认「修复说明」：每类问题怎么修、必须满足什么条件；逐条修复的问题/做法/依据/注意事项；未修复的原因；候选方案。点「看对比」进入修复前后数据 | 点左侧列表或「看对比」 |

`←` `→` 切换步骤，`1`–`3` 直达，`Esc` 关闭弹层；产物列表里的文件可点开预览。

## 实时运行与回放

- 「实时运行」现场真跑算子；「回放」按原始节奏重放上一次记录。
- 运行失败时上一次成功结果不被覆盖，页面提示改用回放。
- 每步右侧「查看上次结果」可直接打开最近一次输出，不必重跑。
- **`runs/` 不入库**（含修复副本 Parquet）。首次使用请先在本机实跑一次检测与修复，回放记录与硬件信息才会生成为本机数据。

## 建议演示节奏（约 3 分钟）

1. 第 1 步 50 秒：按空格，看计时与点阵；跑完指 KPI，再点全景图一行看单条轨迹的画面与问题区间。
2. 第 2 步 60 秒：按空格，修复副本逐个出现；讲三档对比（4,985 → 7,906 → 8,881 帧）与「证据不足、主动拒修 35 项」。
3. 第 3 步 70 秒：扫一遍修复规则表与逐条说明；点 ep29 / ep48 看相机重对齐的逐格审计，ep80 看 Rotation-6D 约束解出，ep74 看相关度不足而拒修。

## 修复对比可看的例子

| 轨迹 | 问题 | 修法 | 结果 |
|---|---|---|---|
| ep29 | 左腕相机整体错位 +5 帧 | 跨相机强相关 r=0.90，path 回移 5 帧，端点置空 | 80.00 → 98.95 |
| ep48 | 右腕相机整体错位 +10 帧 | 本臂运动相关 r=0.909，回移 10 帧 | 80.00 → 97.42 |
| ep80 | state 稀疏 NaN | Rotation-6D 按正交约束解出，其余分量插值 | 97.91 → 100.00 |
| ep54 | 末端位置单帧越界 | 只改越界分量，取前后帧均值 | 99.63 → 100.00 |
| ep06 / ep11 / ep72 | 任务标签与元数据不一致 | 按元数据统一，不动其他列 | 80/90 → 100 |
| ep74 | 同为 +3 偏移，但 r 仅 0.14–0.16 | **拒修**，保持隔离并写入候选 | 80.00（不变） |

## 配置

`demo_config.json`（相对本目录；可用环境变量覆盖）：

| 字段 | 环境变量 | 说明 |
|---|---|---|
| `operator_dir` | `RSQA_DEMO_OPERATOR` | 算子目录，默认 `../03_复赛算子/Raw_data` |
| `input_dir` | `RSQA_DEMO_INPUT` | 赛题测试集目录（不入库，需本地放置） |
| `runs_dir` | `RSQA_DEMO_RUNS` | 运行与回放记录目录，默认 `runs` |
| `platform_summary` | `RSQA_DEMO_PLATFORM` | 可选；缺失时页面不显示平台数据 |
| `port` | — | 默认 8765 |

`input_dir` 默认指向 `../具身智能多模态数据质量检测算法赛题-初赛数据/初赛数据/测试集`，
该目录被 `.gitignore` 排除（赛题数据版权归组委会），需自行从赛事方获取后放到该位置。

## 口径

- 现场跑的是**赛题公开测试集**（本机，89 条 / 17,213 行）。
- 可训练帧：全盘丢弃 4,985 → 只检测+切段 7,906 → 检测+修复+切段 8,881（**+78.2%**）。
- 页面**不出现**用真实标签计算的准确率/召回率；本演示只承担检测、修复、对比三件事。
