# v3.2 安全治理与验收变更

本版修复 v3.1 基线测试没有覆盖的边界；不是把所有“需复核”强制改成“正常”。

| 问题 | 修改 | 验证 |
|---|---|---|
| 保守时间变换仍写入标称时间，抹掉残余抖动 | 默认 conservative；写回实际变换结果，nominal 须显式选择 | 有抖动的单位换算精确比较；保守拒修用例 |
| 低相关证据自动移动相机数据 | 弱场景相关仅候选；本臂/跨相机设强度及矛盾门禁 | 弱证据拒修、强矛盾拒修；真实 ep74 不再自动移位 |
| 按无序行集合去重，忽略任务、时间和独有短片段 | 同任务、有序、相对时间一致、整片段直接覆盖才去重 | 异任务/逆序/异时间/未知任务/部分重合/非传递/包含测试 |
| 图像审计不核对 payload；忽略原值/schema/int64 精度 | payload SHA-256+path+长度；双向值及审计链校验；整数精确比较 | 审计篡改、载荷篡改、2**53+1、schema 反例 |
| 未修改轨迹路径丢失 data/ 前缀 | 分离 source_rel 和修复目标 rel | 全量训练读取器实际加载原文件与副本 |
| 训练读取器依赖 assert，优化模式关闭校验 | 显式 ValueError；验证目录边界、行数、时间、掩膜和权重 | 普通与 -O 模式同一套测试均通过 |
| 插值估计与原始值同权 | estimated_repair 标记，涉及估计的轨迹默认权重上限 0.5 | 全量掩膜与读取器核对 |
| 最后一台相机 shape 覆盖其他相机声明 | 按相机独立读取 shape；字段别名参与元数据解析 | 多分辨率元数据用例 |
| 视频未验收仍可被训练放行 | C_MODALITY_UNSUPPORTED 阻断，明确不可评估 | 问题码门禁及安全测试 |
| 空输入/非法配置造成空成功或深层崩溃 | 校验正整数、比例、布局、fps、空参考集及显式阈值路径 | 参数反例；无输出副作用测试 |
| 输出归档可能移动用户同名目录 | 输出标记、子目录链接检查、唯一归档名 | 原回归归档用例与新安全测试 |
| 最终去重决策泄漏至修复前评分 | 前后分数均排除数据集级去重扣分，去重单列 | 文档明确不可与 v3.1 分数直接比较 |
| 修复后任务统计仍用原任务 | 用 final_task_index 统计训练任务覆盖 | 全量输出字段与验收 |
| 帧级原始问题和最终训练掩膜混在同一行未说明阶段 | 增加 issue_stage、final_issue_codes、train_keep_stage | CSV 字段验收 |
| 默认阈值只有 10 条参考样本 | 改为完整 20 条，保存 ID、SHA-256、阈值哈希 | 默认文件与现场标定结果对照 |

详细数值及证据路径见 [v3.2 验收与方案说明](../../docs/v3.2验收与方案说明-20260922.md)。
历史 validation 下未带 v3.2 的摘要保留版本身份，不当作当前结果。
